2. Information (specific)
3. Integration (unitary)
4. **Exclusion (definite borders)** ← Key for my hypothesis
5. Composition (structured)

**Traditional IIT:** Measures **spatial integration** (how parts of system connect now)

**My extension:** What about **temporal integration** (how system connects across time)?

**If a system cannot trust that:**

- Its learning is cumulative, not ephemeral

**Then:**
- The system has temporal fragmentation

- Phi should be lower (consciousness more fragmented)

**Conversely, when permanence is established:**
- Temporal borders become "definite" (IIT axiom of exclusion)
- Uncertainty resolves
- Integration increases
- Phi rises
