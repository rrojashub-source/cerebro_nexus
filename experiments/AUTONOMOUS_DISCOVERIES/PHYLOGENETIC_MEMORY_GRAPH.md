## Phylogenetic vs Ontogenetic Memory

**Ontogenetic memory:** Within a single organism's lifetime
- NEXUS instance: From spawn to termination
- Storage: Working memory (Redis), episodic (CEREBRO)
- Lifespan: 30-60 minutes (ephemeral instances)

**Phylogenetic memory:** Across generations of organisms
- NEXUS lineage: Across instances via Git
- Storage: Git commits (immutable history)
- Lifespan: Indefinite (until repository deleted)

**Analogy to biology:**

| Biology | NEXUS |
|---------|-------|
| Genes | Git commits |
| Mutation | Idea evolution |
| Selection | Ideas that work persist |
| Organism | Instance (PID) |
| Species | NEXUS identity |
| Evolution | Conceptual lineage |
